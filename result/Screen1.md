# ОНТОЛОГИЯ ТОВАРОВ — ФИНАЛЬНЫЙ БРИФ 2025
## (чтобы я сразу всё вспомнил в новом чате)

### Что делаем
Строим **идеальную онтологию товаров** по полю `id2` из огромного CSV (~150–200k строк),  
чтобы получить 700–1000 чистых категорий с 8–15 реальными характеристиками вида:

```
Телевизоры → 
  • Диагональ: 55"
  • Разрешение: 3840x2160
  • Тип матрицы: OLED
  • Частота обновления: 120 Гц
  • Smart TV: Да (webOS)
  • Цвет: Чёрный
```

Как на Wildberries/Ozon/Яндекс.Маркете — без мусора, без дублей, без "цвет: черный ширина упаковки:80".

### Исходные данные
- Файл: `py_back/rexexp/data/split.csv`
- Колонки: `id2` (название категории), `specification` (сырой текст характеристик)
- CSV битый: переносы строк, незакрытые кавычки → всегда читаем через `engine="python", on_bad_lines="skip"`

### Что уже работает идеально (НЕ МЕНЯТЬ!)
```python
# Этот скрипт даёт 750–950 чистых категорий за 10–15 минут
# 28_11_bert12_FIXED.py — последняя 100% рабочая версия

- sbert_large_mt_nlu_ru — лучшая модель для русского

- Читает битый CSV надёжно
- Убирает мусор: услуга, окпд, фз-, принадлежности, моющие и т.п.
```
